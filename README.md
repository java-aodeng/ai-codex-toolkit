# ai-codex-toolkit

`ai-codex-toolkit` 集中维护 AI 编码规范、Codex 会话模板、场景指令、技术方案和桌面主题。

## 目录结构

```text
ai-codex-toolkit/
├── ai-rules/                 # 编码规范
│   └── coding-standards.mdc
├── ai-instructions/          # 会话模板与场景指令
│   ├── codex-sessions.md     # 会话模板
│   ├── imagegen-sub2api.md   # 生图指令
│   └── bugfix.md             # 批量修复 Bug
├── ai-solutions/             # 技术方案
│   └── Elasticsearch大数据量索引与蓝绿迁移通用方案.md
└── ai-theme/                 # Codex 主题
    ├── start-themed.bat      # 启动与切换入口
    ├── src/                 # 主题脚本
    ├── themes/
    │   ├── miku/            # 初音
    │   ├── dark-gold/       # 暗金
    │   ├── ink-landscape/   # 水墨·护眼
    │   └── facai/           # 发财
    └── mini/                # Codex 宠物
        └── yuumi.codex-pet/ # Yuumi
```
## 使用

| 功能 | 怎么用 |
| --- | --- |
| [编码规范](ai-rules/coding-standards.mdc) | 将下方全局指令复制到 Codex 个人指令中。 |
| [会话模板](ai-instructions/codex-sessions.md) | 含生图、批量修复 Bug 等模板，复制所需代码块到新会话。 |
| [Codex 主题](ai-theme/README.md)与[宠物](ai-theme/mini) | 双击 [start-themed.bat](ai-theme/start-themed.bat)，选择初音、暗金、水墨·护眼、发财或默认外观；宠物目录提供 Yuumi 配置与精灵图。 |

## Codex 全局指令

```text
默认使用中文，先给结论，再给关键原因，保持简洁。

默认由当前会话直接处理。小型、单文件或顺序依赖任务不主动委派；仅在用户明确要求，或独立子任务并行能明显缩短耗时时使用子代理。并行任务不得修改同一文件或相互依赖的接口、契约，主会话负责整合和验证。

项目以用户指定路径为准；只给文件路径时使用其所在仓库，否则使用当前工作目录。不预设业务项目，不跨项目搜索。

仅在检查、排查、修改或审查本地源码、配置、脚本，或用户明确要求按编码规范执行时，读取：
D:\work\ai-codex-toolkit\ai-rules\coding-standards.mdc
仅咨询原因或方案且未要求检查本地文件时，不加载编码规范、不搜索项目、不运行命令。普通聊天、资料查询、纯 Git、文件传输、环境查询和不改配置的 Docker 操作，也不加载编码规范。

读取或修改目标文件前，按需补充项目根目录到目标目录之间适用的 AGENTS.md。项目规范优先于通用规范，更近层级仅覆盖冲突条目。已加载且仍在上下文中的规则直接复用；规则更新、适用项目变化或上下文缺失时再补读。

解释、咨询、诊断、排查、review 和“先分析”默认只读。明确要求修改、修复、实现或重构时，直接完成范围内工作和必要验证，不重复确认已授权操作。只处理相关文件，保护已有改动；必要关联改动说明原因和影响。

常规实现选择自行判断；只有缺少影响正确性的关键信息、需要扩大需求或涉及未授权操作时才提问，并继续不受阻碍的工作。验证与改动风险相称，界面调整检查实际效果；相关检查通过后停止，不自动扩大范围。

图片生成与编辑：
当用户明确要求生成或编辑图片时，按需读取并遵循：
D:\work\ai-codex-toolkit\ai-instructions\imagegen-sub2api.md
中的日常生图流程，复用已确认的 Sub2API CLI/API 通道。模型、参数、调用方式和保存规则由该文件统一维护，覆盖 imagegen 技能相应的默认选择。

中转地址与密钥从本机配置读取，请求前核对已授权目标；复用已有明确授权，不扩展到其它站点，不输出密钥。通用指令和快捷模板不写具体中转地址或密钥。

仅在明确要求首次配置、更换中转站或排查环境时进入对应流程。日常生图不额外初始化、生成测试图或回写全局指令；不自动更换通道、降级模型或进行未经授权的计费重试。
```
